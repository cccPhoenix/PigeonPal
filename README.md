# 鸽友 PigeonPal 🕊️

把分散的校园通知、课程作业和自己的待办放在一起，有新消息或提醒到点时，让小浙来叫你。

鸽友是面向浙大学生的本地桌面校园伙伴：可以看通知、查作业、记提醒，也能通过 DeepSeek 帮你总结信息、润色文字。它是学生开发的独立项目，非学校官方应用。

## 能帮我做什么？

| 场景 | 鸽友能做的事 |
| --- | --- |
| 不想反复打开学校网站 | 定期检查下列来源，集中显示通知标题、内容与原文链接；有新通知时主动提示 |
| 怕漏看奖学金、讲座或活动 | 配置自己的身份和关注方向后，辅助推荐；不确定是否适用的通知继续保留，也可以查看「全部通知」 |
| 作业多、截止时间容易混 | 登录后查看学在浙大作业的课程、截止时间和提交状态；提供截止前 6 小时提醒 |
| 想把事情记下来 | 表单设置提醒，或配置 API 后说「今晚九点提醒我完成数学作业」；支持修改、取消、延后 |
| 想快速看懂一份通知 | 配置 API 后整理通知要点，带着原通知继续提问；重要日期和资格以原文为准 |
| 想写总结、改文字 | 在聊天里生成个人总结、润色表达；支持 Markdown 排版与复制 |
| 想看近期安排 | 日历汇总通知、作业、提醒，也可以添加自己的事项 |

## 下载与安装

在 [Releases](https://github.com/cccPhoenix/PigeonPal/releases) 下载 **v0.3.1** 对应系统的文件，无需另装 Python、Node.js 或开发环境。

| 你的电脑 | 安装文件 | 当前状态 |
| --- | --- | --- |
| Windows 10 / 11，Intel 或 AMD 64 位 | `PigeonPal-Setup-0.3.1-x64.exe` | 已在 Windows x64 构建并通过解包应用离线验收；安装流程待一次性 VM 验证 |
| macOS，Apple 芯片（M1 / M2 / M3 / M4 等） | `PigeonPal-0.3.1-mac-arm64.dmg` | 已构建并通过本机离线验收 |

- **Windows：**打开 `.exe`，按向导安装，从桌面或开始菜单启动「鸽友 PigeonPal」。
- **Mac：**打开 `.dmg`，将「鸽友 PigeonPal」拖入「应用程序」，再从应用程序打开。Intel Mac 暂不提供安装包。
- 当前是试用版本：Windows 尚无发布者代码签名，Mac 使用临时签名、尚未通过 Apple 公证，系统可能提示无法验证开发者。如果系统阻止打开，请保留提示并联系开发者确认，不需要关闭系统安全功能。
- 不需要删除旧数据来升级；先从托盘 / 菜单栏退出旧版，再安装新版。安装包与各平台实际检查结果见 [桌面版说明](docs/desktop.md)。
- Windows 的首次启动报告、`SHA256SUMS-windows.txt` 和[实际验收记录](docs/windows-0.3.1-acceptance.md)随 Release 提供。系统通知显示、通知点击和托盘鼠标操作仍待真实桌面确认。

## 第一次打开，按这几步设置

1. **先看看通知。** 左侧铃铛进入通知，选择来源；公开通知会逐步同步。点击一条看详情，点击原文链接回学校网页。列表和详情均可星标置顶、移入回收站；回收站支持恢复。可按系统推荐程度、发布时间从新到旧／从旧到新、通知类型排序，星标始终优先；排序选择会在重启后保留。
2. **需要作业和 ITC 时绑定账号。** 左下角「我的设置 → 身份认证」，自行输入 ZJUAM 账号密码。认证成功后，站点会分别建立会话；如果某个来源仍报错，在应用里查看该来源状态。
3. **需要聊天和自动整理时配置 API。** 「我的设置 → API 设置 → 添加 API」，填自己的 DeepSeek Key，保存并验证。API 按服务商用量计费；鸽友不自带共享 Key。
4. **可选：完善用户画像。** 点击侧栏「用户画像」，选择所属学园，填写身份、入学年份和偏好。学园可选云峰、丹阳青溪、蓝田，默认保留全部；选择后其他学园不再主动推送，公共来源继续保留，「全部通知」仍可查看原始信息。只有你确认的身份事实才用于资格判断。
5. **试一下提醒。** 聊天输入框旁的「＋ → 设一个提醒」无需 API。也可以在「我的设置 → 提醒」使用「5 秒后来一条提醒」检查。若要系统弹窗，请同时检查「主动消息」设置及系统通知权限。
6. **选一个喜欢的形象。** 点击小浙头像更换形象、称呼；「外观」可调整主题和动效。觉得动态太多可选「克制」或「关闭」。

**没有 API Key 也能用：**原始通知、已认证后的作业、本地日历、表单提醒都可使用。聊天、文字润色和模型整理需要配置 API。

## 关闭窗口后，还会提醒吗？

会，**关闭窗口会留在系统托盘 / Mac 菜单栏，继续抓取和调度提醒**。从托盘重新打开，选择「退出鸽友」才彻底停止。默认不会自动设置开机启动。

- 电脑关机、休眠或彻底退出时，应用无法实时提醒；重新运行后会补收仍待处理的到期提醒。
- 默认安静时段为 **23:00–07:30（北京时间）**，可在「主动消息」调整；安静期间保留记录，不弹窗，结束后不会集中补弹。
- 提醒在本机保存和调度，**到期触发不消耗模型 API**。自然语言理解提醒、对话和通知整理可能消耗 API。
- 系统免打扰、通知权限或某来源静音，也会影响弹窗。可以在应用内查看提醒记录。

## 我的账号和数据放在哪里？

通知、作业、提醒和聊天记录主要保存在自己的电脑上。校园凭据和 API Key 由本机服务加密保存，安装包不含开发者账号、Key 或个人通知。

- Windows：`%APPDATA%\PigeonPal`
- Mac：`~/Library/Application Support/PigeonPal`

**本地保存不等于所有内容都离线处理：**配置模型后，你发送的聊天、主动引用的通知、启用整理的通知正文及用于推荐的已确认画像可能发送给所配置的模型服务。受保护通知是否允许整理可单独设置。**学在浙大作业的自动整理、清单查询和提醒在本机处理，不自动发送给模型。**

不要把整个数据目录发给他人；里面可能包含认证材料和个人记录。不要在聊天中输入密码或 API Key，请使用对应设置页面。

## 常见问题

**刚装好没有通知？**

先保持联网并等一轮同步；公开来源无需校园账号，ITC 和作业需要先认证。首次正文会分批补齐。「推荐」为空时，也看看「全部通知」。不同站点访问条件可能不同，认证成功不代表每个站点都能立即访问。

**聊天不能回复，但通知能看？**

检查 API 是否已添加、验证并设为当前配置，以及服务商额度是否充足。未配置 API 不影响表单提醒和原始通知。

**没有收到系统弹窗？**

确认鸽友仍在托盘 / 菜单栏运行，检查系统通知权限、免打扰、应用主动消息开关、来源静音和安静时段。先用 5 秒演示提醒核对，系统弹窗与聊天中的消息不是同一个开关。

**升级后需要重新绑定？**

同一桌面应用的数据目录通常会保留。早期开发网页版和桌面版的认证存储不同，首次使用桌面版可能需要重新绑定。不要直接复制他人的认证目录。

**反馈问题时发什么？**

到 [Issues](https://github.com/cccPhoenix/PigeonPal/issues) 描述系统、版本、操作步骤和报错截图。不要上传密码、Key、Cookie、完整学号或整个数据目录。

## 想参与开发？

源码运行需要 Python 3.10+；使用 npm 入口时另需 Node.js。桌面构建使用 Node.js 22.12+ 和 Python 3.12。

```sh
python -m pip install -r requirements.txt
npm run dev                 # http://127.0.0.1:4174
npm test
python -m unittest discover -s tests -p 'test_*.py'
```

也可直接运行 `python scripts/serve.py`。开发入口与正式安装包使用不同的认证 / 界面存储，避免同时向同一数据目录启动多个服务。
