# 丹阳青溪与蓝田消息源

本次更新基于 2026-10-29 获取的主线 `d133c01`，沿用桌面版的采集、模型整理、推荐、消息投递及本机数据目录。初版为 0.3.2，通知栏与选择器的后续调整为 0.3.3；构建产物不含用户账号、API Key 或通知数据。

- 丹阳青溪：`https://dqxy.zju.edu.cn/51432/list.htm`，读取最新通知首屏 `#wp_news_w6`。
- 蓝田：`http://lantian.zju.edu.cn/ltoffice/main.htm`，读取通知栏 `#wp_news_w51`，排除重复的综合资讯栏。
- 两站读取 `.news_title a` 的完整标题、`.news_meta` 日期和文章 ID；正文复用云峰的 WebPlus 解析器，保留正文与附件链接。
- 每五分钟检查入口，新文章进入原有增量队列，同站请求保持 15–30 秒间隔，不遍历历史分页或下载附件。
- 默认按现有云峰方式直接访问，不增加 VPN 配置；网络失败按来源退避重试。

在侧边栏「用户画像 → 我的身份 → 所属学园」自行选择云峰、丹阳青溪、蓝田或全部学园并保存。学园选择存于本机画像，旧画像缺少此字段时按全部学园读取，其他画像字段保留。保存后，通知栏仅保留所选学园的入口和通知，求是学院、本科生院、ITC 与学在浙大不受影响；原始数据不删除，选择「全部学园」即可恢复。学园选择由本机处理，不发送给模型。

模板已通过官网和用户已登录的 WebVPN 核对。此前蓝田直接试抓得到 9 条通知元信息、1 篇完整正文；丹青模板与附件提取验证通过，但当时直接请求遇到网络错误，不据此宣称直连采集成功。
