# PigeonPal 第一版 UI 设计说明

日期：2026-10-13。本文取代 `archive/` 中的旧版说明（docs/superpowers）。

## 定位

一个桌面端的校园伙伴。它有固定身份，默认叫「小浙」，会盯着各个网站的消息，有事主动来告诉你，也能帮你记提醒、陪你聊两句。目标是让人感觉在和一个真人聊天，而不是在用一个 AI 工具。

参考 DS Bot 的交互骨架，但不做多 bot、群聊和插件。第一版先把 UI 做完整，模型、抓取、调度都只留接口（见 `interfaces.md`）。

## 原则：去掉"AI 味"

- 不出现快捷指令按钮、免责小字、「思考过程」、工具日志这类元素。
- 功能尽量通过对话完成。「提醒我」直接说，不需要单独打开管理页。
- 消息要短，可以分几条发；回复前有"正在输入"，时长按字数计算。
- 头像是活的：最新一组消息的头像会呼吸、眨眼，思考时歪头，来消息时跳一下。

## 布局

三栏：**图标栏（64px）· 通知主体 · 对话**。

- **图标栏**：品牌图标、小浙的活体头像（点击即对话，窄屏下用来唤出对话抽屉）、视图切换（通知／日历）、搜索、添加信息来源、「我」。图标悬停时向右展开文字标题，所以窄栏不必靠猜图标含义。
- **通知主体**（中间，主视觉）：左列是按日期分组、可按来源筛选的通知列表，带未读数；右侧是选中通知的详情表格。≤720px 时合并为「列表 → 详情」单栏切换，详情顶部出现返回。
- **对话**（右侧）：顶部居中的小浙胶囊、消息流、输入框。≥1100px 常驻，中间的分隔线可拖拽调整它与通知主体的宽度比例（键盘方向键同样可调，宽度会记住）；更窄时收为右侧抽屉，抽屉内有关闭按钮。

## 消息类型

- **通知**：不以对话气泡呈现。爬虫抓到新通知后，小浙只在对话里留一句短提示（点击可跳到通知栏的对应条目），通知本身进入通知主体的列表，点开以表格排版呈现：来源、发布日期、整理状态、通知类型、参与方式、面向、要点、时间、地点、截止、收益、分类、待办、备注，以及详情接口补出的发布者、采集状态、附件与网页正文。
- **把通知作为提问的上下文**：从列表把通知拖进输入框，或点详情里的「添加到对话」，生成一枚附件 chip；发送时该通知的结构化字段与正文会作为资料交给模型。正文尚未采集完整的通知不能附加，界面上也不可拖拽。
- **到点提醒**：主动发来，单独成组。普通提醒说「{称呼}，21:00 啦 ⏰ 该完成数学作业了～」；通知类提醒说「还有 30 分钟开始！在 xx，不要忘记哦～」。下方附「完成」「10 分钟后」。

## 首次使用

小浙先打招呼，再问「我该怎么称呼你呀？」，用户的回答会被设成称呼。

## 视觉

近白背景，浅灰图标栏与通知列表栏；主体控件保持黑白灰，链接与通知选中态的低饱和度强调色随所选虚拟形象变化，上传形象则从图片提取主色。使用系统中文字体，正文 15px / 24px。通知详情表只保留发丝横线、不设竖线与斑马纹。支持深色模式（跟随系统，也可手动切换）。动效使用弹性曲线；用户可在「灵动 / 克制 / 关闭」之间选择，系统「减少动态效果」开启时同样生效。

## 形象

槽位默认是中性的占位形象。保留两版鸽子草图（团子鸽、信鸽），并按 `images/character0.png` 至 `character9.png` 新增 10 款分层 SVG 候选角色，可在设置里切换，也可以在 `lab.html` 预览所有动作。鼠标跟随只作用于眼珠，眼白和眼眶固定。接入约定见 `avatar.md`。
