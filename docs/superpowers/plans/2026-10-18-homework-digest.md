# 作业默认摘要与本地查询

目标：默认只展示最近五条明确未提交的当前作业与三条临近截止的当前作业，去重后按截止时间从早到晚排列；截图中的自然语言查询直接返回本地事实，不把作业发给模型。

约定：排除已提交、已关闭、明确过期、明确旧学期及尚未开放的任务。课程编码无学期信息时按有效开放/截止信息判断；不从抓取时间推断旧作业仍有效。提交状态未知不冒充未提交，只可在临近截止组中如实展示。无截止时间放最后。最近以开放时间优先、收录时间兜底。保留底层历史数据、普通聊天及手工提醒；六小时提醒继续独立运行。

- [x] 后端共享筛选：默认最多八条、两组去重；采集器跳过明确旧学期课程；提醒取消旧任务。
- [x] 本地查询：截图两条原话、中文/数字数量、近远排序、无 Key 查询；结果不进入后续模型历史或引用。
- [x] 界面快照：替换普通作业卡片而非无限追加；恢复旧缓存时缩减；每轮最多一次新消息提示；保留聊天/提醒与头像节点。
- [x] 验证：混合学期、过期/关闭/未知状态、默认 5+3、查询结果、旧缓存和多轮快照；原提醒/模型隔离相关离线回归。
- [x] 隔离运行界面验收：合成历史/当前作业、种入旧缓存、验证最多八张卡片、查询五条与重载/重复轮询；不访问学校或模型。
- [x] 静态审查与复审完成；准备合入本地 main，用户未要求本次推送。

验收证据：合成 93 条混合学期记录和同规模旧缓存，实际页面重载后八张卡片、旧学期不可见、原聊天保留；两条截图原话在无模型 Key 的主聊天均返回五条。提交一条后后台默认七条，页面下一次轮询自动移除该任务，聊天仍保留。本机实际历史 156 条只读筛选得到五条默认记录，无旧学期混入。
