# 鸽友 Windows 桌面版与可靠提醒

用户目标：详细检查抓取/提醒，修复缺陷，提供同学可安装的 Windows exe，有新通知或提醒到期时弹出系统通知。

沿用单伙伴 UI、已有四类校园通知与学在浙大作业、原有数据/认证/本地模型边界。安装包包括 Python 运行时和加密依赖，普通用户无需开发环境。设计选择（实现方决定）：Electron + PyInstaller sidecar + electron-builder NSIS，Windows x64 首版。Windows 原生编译/安装与通知验收不可由 macOS 单元测试替代。

窗口默认关闭到托盘（已询问用户，可按反馈调整），明确“退出鸽友”停止进程。仅一个应用实例。子服务绑定随机 loopback 端口；由父进程私有管道获知真实地址；固定 pigeonpal://app 来源并通过受限协议处理器代理自有后端，端口变化不丢失 UI 数据。服务异常退出给出明确错误，不能静默显示正常采集。退出/父进程消失时停止子服务，锁正常释放；不影响另一个开发服务。数据、校园凭据/API keys 永不打包/上传；数据在用户专属目录，更新安装保留数据。

系统通知独立于 renderer 生命周期，由 main process 周期读本机已抓取数据和持久提醒事件。每个来源首次成功同步后为已有通知建立基线，首次认证历史数据不逐条弹窗，只按通知 ID 识别新到达（模型整理状态变化不重复提示），后续新通知即使离线/隐藏超过一分钟也能提示；到期提醒跨重启补收，按提醒 ID 与 deliveredAt 去重，从完整提醒表恢复以避开 2000 条事件日志保留上限。消息成功保留后记录游标。OS toast API 失败保持可重试；系统主动屏蔽无法伪称已显示。大量积压合并提示，正常单条显示概要。尊重用户开启/关闭系统提醒、总主动开关、频道静音和北京时间安静时段。点击通知恢复窗口并进入对应频道。浏览器版保留现有权限机制；桌面版由原生层唯一投递，避免重复。

桌面 preload 只暴露固定的偏好同步、通知状态和跳转订阅，不暴露通用 IPC/fetch/命令执行；contextIsolation/sandbox 开启，Node integration 关闭，只允许自身本机页面，外链经 HTTPS/HTTP scheme 校验交系统浏览器，禁止页面导航到任意来源/子窗口/下载/不必要权限。

验收：现有 Python/JS suite、失败用例的离线回归、抓取 source 隔离/恢复、提醒创建/修改/取消/延后/重启/写盘失败；桌面通知去重/首轮/重启/静音/时间边界；冻结 backend 的 loopback API/打包后运行；Windows CI 编译并 smoke test sidecar 和安装后启动/退出，产出 exe + SHA256；真实校园授权和 Windows 桌面实际 toast/点击/托盘留待目标系统证据，不用假数据测试宣称通过。

抑制策略：静音/安静时段消息保留在会话，系统通知消费后不补弹，避免早晨集中骚扰；OS API 失败才重试。提醒只发送仍为 pending 且已到期投递的记录，取消/完成后不补弹。OS toast 和磁盘事务无法实现跨系统严格 exactly-once：优先不丢，写盘失败时可能重复一次。父进程私有 stdin 管道 EOF 触发子服务关闭，正常退出有 12 秒有界兜底。Windows CI smoke 不等价于真实交互通知验收。
