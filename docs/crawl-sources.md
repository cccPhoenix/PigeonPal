## 手动运行

在仓库目录执行：

```sh
python scripts/crawl_yunfeng.py
```

仅依赖 Python 3.10+ 的标准库。每次手动运行读取一次首页和最新 3 篇正文；重定向请求同样遵守 15–30 秒间隔。脚本不自动重试，遇到异常会停止本轮并保存已经取得的结果。

结果默认写入 `data/yunfeng-notices.json`，包含首页全部条目、3 篇正文、附件名称与链接，以及请求时间和状态记录。`publishedAt` 保留网站的 `YYYY-MM-DD` 日期；这是爬虫输出，尚未接入前端服务。`data/` 已加入 `.gitignore`。

2026-10-13 首次试抓已完成：14 条首页元信息、3 篇非空正文、12 个附件链接。共 7 次 HTML 请求（含跳转），日志中的相邻请求间隔为 29、25、27、17、22、26 秒。未请求附件、历史分页或其他候选站点。
