# 形象接入约定

形象（代码里叫 mark）是一个可替换的槽位。侧栏卡片、顶部胶囊、消息头像和设置页都调用同一个组件，替换一次，所有位置一起生效。

## 两种接入方式

### 1. 图片（最快）

在「设置 → 形象与称呼 → 上传图片」上传 PNG、SVG、GIF 或 WebP 文件，大小不超过 1.5MB。图片按圆形裁切，动作只有整体的浮动、跳动和弹出。

### 2. 分层 SVG（推荐）

画布为 `100×100`，在 `web/js/mark/looks.js` 中注册：

```js
registerLook('mine', {
  label: '我的形象',
  note: '一句说明',
  svg: () => `...`,
})
```

按下面的约定给图层加 class，就能获得全部动作：

| class | 必需 | 用途 |
|---|---|---|
| `.mk-shadow` | 否 | 地面阴影，放在 `.mk-body` 外面。跳起时会缩小 |
| `.mk-body` | 是 | 整体，负责呼吸、歪头、跳、蹭、转圈 |
| `.mk-eyes` | 是 | 眼睛组，会跟随鼠标，思考时向上看 |
| `.mk-eye` | 是 | 每只睁开的眼睛（填充色用 `--mk-ink`），负责眨眼 |
| `.mk-happy` | 否 | 开心闭眼（描边路径），被摸时代替 `.mk-eye` 显示 |
| `.mk-wing-l` / `.mk-wing-r` | 否 | 翅膀，来消息时扑动 |

建议：
- 用单色块面，不用渐变和描边。36px 下依然能认出来最重要。
- 不要在 SVG 里写 `id`，因为同一页面会同时出现很多个实例。
- 眼睛用 `class="mk-eye"`，不写 fill，颜色由主题统一控制。

## 状态

| 状态 | 触发时机 | 动作 |
|---|---|---|
| `idle` | 默认 | 呼吸、随机眨眼 |
| `thinking` | 正在输入回复 | 歪头、眼睛向上看 |
| `alert` | 新通知或提醒到点（一次性） | 跳两下、扑翅膀 |
| `happy` | 鼠标悬停在大头像上 | 蹭、闭眼笑 |
| 点击 | 大头像 | 转一圈 |

只有带 `live` 的实例会动：侧栏卡片、顶部胶囊，以及对话里最新一组消息的头像。旧消息的头像保持静止，阅读时不会分心。设置里的「动效：克制 / 关闭」和系统的「减少动态效果」都会生效。

所有动作都可以在 `web/lab.html`（形象实验室）里逐一预览。
