# 鸽友 v0.4.0

## 通知管理

- 修复来源分类与侧栏铃铛的未读计数同步；同一通知的更新不会重复累加未读。
- 通知支持星标置顶、移入回收站与恢复；星标和回收站状态在重启后保留。
- 支持按推荐程度、发布时间从新到旧／从旧到新、通知类型排序。

## 软件更新

- 新增「设置 → 软件更新」，展示当前版本、检查结果与更新说明。
- 可开启或关闭自动检查更新；默认在启动后及每 24 小时检查一次，也可手动检查。
- Windows 支持手动下载更新、查看进度、重启并安装；正常退出不会擅自安装。
- 下载完成并经校验后才允许安装；安装前保存界面状态并关闭 Python 后台。
- macOS 提供版本检测、更新说明与官方 DMG 下载入口，当前需手动替换应用。

## 安装说明

- Windows x64 使用 `PigeonPal-Setup-0.4.0-x64.exe`。
- Apple Silicon Mac 使用 `PigeonPal-0.4.0-mac-arm64.dmg`，仅在附件中实际提供该文件时表示此平台构建已完成。
- 退出托盘／菜单栏中的旧版后安装，用户数据目录继续保留。
- 当前 Windows 包尚无发布者代码签名；Mac 使用临时签名、尚未公证。没有绕过系统验证的自动安装路径。
- 升级不会自带任何开发者账号、API Key 或个人通知。
