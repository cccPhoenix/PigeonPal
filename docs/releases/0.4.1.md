# 鸽友 PigeonPal 0.4.1

新增丹阳青溪学园、蓝田学园消息来源，沿用现有定时检查、增量采集与本机存储。

在「用户画像 → 所属学园」选择云峰、丹阳青溪或蓝田并保存后，通知栏只保留所选学园的入口和消息，公共来源继续显示。切回「全部学园」即可恢复其他学园；原始通知不会删除。

学园选择器采用统一的卡片菜单，支持选中提示、方向键、Enter、Esc 和点击外部关闭。保存后立即切页、重新打开软件时，学园选择也会同步到通知栏和未读数。

保留 0.4.0 的应用内更新功能；本版还改善 Windows 首次加载多个网页模块时的响应速度。更新不会清空已有账号、API 配置、画像或通知数据。

0.3.x 用户需手动安装一次新版，之后可在「设置 → 软件更新」检查后续版本。Windows 安装包尚无发布者签名，macOS 仍使用临时签名；具体平台附件和 SHA256 校验文件见本次 Release。
